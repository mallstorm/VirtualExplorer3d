# Техническое задание - Virtual Reality Explorer Engine

Цель: Android-приложение на Godot 4 для интерактивного исследования виртуальных пространств: заброшенных зданий, исторических мест, промышленных объектов, музеев, археологических объектов и реконструкций помещений.

Пользователь должен ходить внутри пространства, подходить к стенам, осматриваться, смотреть назад, взаимодействовать с объектами и переходить между помещениями.

Первая демонстрационная сцена: `Чернобыльский саркофаг. Блок N4`.

## Типы сцен

- Type A: полноценная 3D-сцена с Player, Camera3D, Collision, стенами, полом, оборудованием и светом.
- Type B: 360 Panorama Scene на основе `4096x2048 JPG`, сферы и камеры внутри.
- Type C: Hybrid Scene, где 3D-помещение объединяется с 360-фотографиями, depth map и будущей AI-реконструкцией.

## Платформа

- Первая версия: Android.
- Минимум: Android 9+, API 28+.
- Поддержка: телефоны, планшеты, VR Cardboard на этапе 2.
- Будущее: Windows, Linux, Web.

## Стек

- Godot Engine 4.x.
- GDScript.
- Forward+ для мощных устройств.
- Mobile Renderer для слабых телефонов.

## Три этапа реализации

### Этап 1 - MVP v0.1

- Godot проект.
- Android сборка.
- 3D игрок.
- Камера.
- Ходьба.
- Стены.
- Освещение.
- Загрузка одной комнаты.

Демонстрация: пользователь находится внутри саркофага, может ходить, подойти к стене, развернуться и посмотреть назад.

### Этап 2 - v0.2

- 360 панорамы.
- Переходы как Google Street View.
- Точки интереса.
- Описания объектов.
- Звук.

### Этап 3 - v0.3+

- Импорт проектов.
- VR режим.
- AI depth.
- Фотограмметрия.

## Производительность

- Android RAM: минимум 4 GB.
- GPU: Adreno 610+.
- FPS: минимум 30, цель 60.
- APK: цель меньше 100 MB.
- Без встроенных огромных библиотек.

## Первый тестовый проект

`Chernobyl Sarcophagus Experience`.

Сцены:

- входной тоннель;
- центральный зал;
- реакторный блок;

Каждая сцена должна поддерживать 3D-помещение, реальные текстуры, звук и интерактивные объекты.
