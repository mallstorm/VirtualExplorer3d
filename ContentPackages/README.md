# ContentPackages

Эта папка хранит исходники внешних ZIP-экскурсий для разработки.

Важно:

- содержимое `ContentPackages/` не должно попадать в APK;
- приложение запускает только плеер и меню проектов;
- экскурсия устанавливается отдельно через ZIP;
- рабочая папка установки внутри приложения: `user://Explorer/Projects`.

Текущий демо-пакет:

- `Chernobyl_Sarcophagus_Experience`

Готовый ZIP для телефона должен называться:

- `Chernobyl_Sarcophagus_Experience.zip`

Для теста на Android положить ZIP в папку `Download` и нажать в приложении `Импорт ZIP`.
