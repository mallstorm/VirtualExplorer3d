# VirtualExplorer3d

**Virtual Explorer** — плеер виртуальных экскурсий на **Godot 4**. Проект рассчитан в первую очередь на Android: пользователь должен ходить внутри виртуальных пространств, подходить к стенам, осматриваться, взаимодействовать с объектами и переходить между 3D-комнатами и 360-панорамами.

Экскурсии устанавливаются отдельными ZIP-пакетами. Первая демонстрационная экскурсия: **Chernobyl Sarcophagus Experience**.

## Управление

### Android

- Левая часть экрана — движение от точки касания: вверх вперёд, вниз назад, влево/вправо в стороны.
- Правая часть экрана — обзор камеры свайпом: поворот на 360 градусов, взгляд назад, вверх к потолку и вниз.
- Кнопка `Действие` — открыть описание объекта, когда прицел наведён на интерактивную точку.
- Кнопка `Журнал` — список уже открытых точек.
- Кнопка `Меню` — пауза, быстрый переход в 360, перезапуск и гироскоп.
- Приложение рассчитано на landscape-режим. Портретная раскладка не используется.

### Windows / Desktop

- `WASD` или стрелки — движение.
- Мышь — обзор.
- `E` или `Enter` — взаимодействие с объектом.
- `Esc`, `M` или `Tab` — открыть/закрыть меню.
- `G` — зарезервировано под gyro mode, переключение также есть в меню.
- `V` — зарезервировано под VR mode.

## Запуск в Godot

1. Открыть папку репозитория в Godot 4.x.
2. Запустить сцену `scenes/Main.tscn`.
3. Импортировать ZIP-проект через меню.
4. Запустить выбранный проект.
5. Пройти маршрут от входного тоннеля к центральному залу, реакторному блоку, пультовой и техническому коридору.
6. Навести камеру на интерактивный объект и нажать `E` или кнопку `Действие` на Android.
7. Войти в светящийся портал для перехода в 360 viewer.

## Внешний ZIP-проект

Демо-экскурсия поставляется отдельно:

- `Chernobyl_Sarcophagus_Experience.zip`

На Android положить ZIP в `Download`, открыть приложение и нажать `Импорт ZIP`.

## Сборка

В репозитории уже есть:

- `export_presets.cfg`;
- `.github/workflows/build.yml`.

После push в `main` GitHub Actions должен выполнить:

- импорт проекта Godot;
- экспорт Windows Desktop;
- экспорт Android Debug APK;
- загрузку artifacts.

Android release signing пока не включён. Для релизного APK/AAB позже потребуются keystore secrets.

## Ограничения текущей версии

- Реальные 3D-модели саркофага пока не добавлены.
- Текущая демо-сцена загружается из внешнего `project.json` и использует процедурную low-poly геометрию без тяжёлых ассетов.
- Панорама и звуки сейчас placeholder, их нужно заменить на реальные ассеты.
- Android file picker пока не подключён нативным плагином; импорт реализован из стандартных путей, включая `Download/Chernobyl_Sarcophagus_Experience.zip`.
- VR, AI Depth и фотограмметрия реализованы как фундамент модулей, не как финальная пользовательская функция.
- Локально проект не экспортировался в этой среде, потому что Godot CLI здесь не установлен. Проверка сборки должна пройти через GitHub Actions.
